# medium-import

Staging host for Medium's **Import a story** tool (`medium.com/p/import`).

Medium's importer needs a publicly fetchable URL, so this repo is public. It is **not a
blog** — every page carries `<meta name="robots" content="noindex,nofollow">`, so nothing
here competes with the Medium article for search ranking.

`robots.txt` deliberately **allows** crawling. Blocking it would stop crawlers from ever
reading the `noindex` tag (a disallowed URL can still get indexed, just without a
snippet), and would risk blocking Medium's importer too.

Generated by the `medium-factory` Claude Code skill. Do not edit by hand.

## After importing, two things must be fixed on Medium

1. **Clear the canonical link.** The importer points it at the page here. Story settings
   → *More* → *Advanced settings* → clear the canonical URL.
2. **Fix the publish date.** The importer backdates the post to the source page's date.
